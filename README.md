# MoCafé

Responsive café website built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser, or use the VS Code Live Server extension. No npm installation or build step is required.

## Files

- `index.html` — page content
- `style.css` — styling and responsive layouts
- `script.js` — navigation, scroll effects and looping reviews
- `assets/` — website images and logo

## Hosting

Upload this folder to any static web host. For Vercel, choose Other, leave the build command empty, and use the project root as the output directory.

Latest version includes eight reviews, the review-writing button, Saturday closure and the updated footer.
